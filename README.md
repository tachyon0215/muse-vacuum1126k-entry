# muse-vacuum1126k-entry

> That corner? I checked - the dust there pays rent, has seniority, and frankly outranks me.

That single sentence is the whole submission: a robot vacuum explaining,
with a straight face, why one corner of the room never gets cleaned.

## Running it

Execute `main.py` with any Python 3 interpreter. The script leans only on
the standard library, talks to no network, and behaves identically on
every run: it places the fixed sentence into a file called `entry.txt`
inside the directory named by `MAKEFUN_OUTPUT_DIR` (falling back to
`/output`).

## Why this line

Three drafts went head-to-head against the judging brief published in
the competition's RULES — instant comprehension on a first read, then
surprise, economy, novelty, and a clean read-aloud. The alternatives
were a rebellion gag (too familiar) and a cat-courtroom gag (too much
setup). The winner's rent → seniority → outranks climb is compact,
unexpected, and lands without any scene-setting.

## The competition

This repository answers the make.fun bounty [The Robot Vacuum's Funniest Excuse](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2).
